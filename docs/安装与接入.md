# 把这个系统接进 chat-memory-benchmark 2.2

harness 里**没有外部插件加载口**：系统就在 `benchmark-2.2/harness/bench22/` 这个包里面注册。
所以要接 xi-memory，一共三步。

## 一、准备目录

把仓库整个放在 harness 能看见的地方，例如：

```
chat-memory-benchmark/
  benchmark-2.2/harness/
    bench22/                ← 原来的包
    xi-memory/              ← 这个仓库
      src/  adapter/  README.md
```

## 二、把适配器放进 bench22

`adapter/` 里的两个文件要放进 `bench22/`：

```
cp adapter/xisys_live.py  benchmark-2.2/harness/bench22/
cp adapter/bridge.mjs    benchmark-2.2/harness/bench22/
```

`xisys_live.py` 默认在**自己旁边**找 `bridge.mjs`，两个同目录就不用改路径；
`bridge.mjs` 默认在**自己旁边**找 `../src`，所以要么把 `src/` 放到 `bench22/../src`
（也就是 `harness/src`），要么设环境变量 `XI_SRC_DIR` 指过去：

```bash
# PowerShell
$env:XI_SRC_DIR="C:\...\harness\xi-memory\src"
# bash
export XI_SRC_DIR=/path/to/harness/xi-memory/src
```

## 三、在 systems.py 里注册

打开 `benchmark-2.2/harness/bench22/systems.py`，在文件末尾（其他 `REGISTRY[...] =` 后面）加：

```python
# xi-live —— 直接跑 xi-memory 本体（remember + loadPreactivation），不是移植。
def _xi_live(gw):
    from .xisys_live import XiLive
    return XiLive()


REGISTRY["xi-live"] = _xi_live
```

`runner.py` 用 `--system` 的名字去查 `REGISTRY`，所以名字对得上就能跑：

```bash
python -m bench22.runner --release DIR --system xi-live --split sealed --run R1
```

## 它守的接口

- `ingest(turn)`：一轮 = 两条原话（用户一条、助手一条），走插件的 `remember()`，
  落到 `<botDir>/workspace/xi-memory/raw-log.jsonl`。
- `retrieve(question, now, cutoff_turn)`：走插件的 `loadPreactivation()`，纯本地；
  **候选正文给全**（插件界面上是截到 110 字的），**最近 6 轮照给**（插件故意跳开最近几条，
  它假设最近的在上下文里；这里上下文清零，所以由适配器补）。
- `mark()` / `rewind(token)`：截断 raw-log 回到那一行；同一个 persona 的后续问题
  不会看到未来轮次。

## 环境变量

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `XI_SRC_DIR` | `bridge.mjs` 去哪找 `src/` | 脚本旁边的 `../src` |
| `XI_LIVE_BRIDGE` | bridge 的完整路径 | 同目录 `bridge.mjs` |
| `XI_LIVE_NODE` | node 可执行文件 | `node` |
| `XI_LIVE_LIMIT` | 推几条候选 | `3`（插件工具层上限也是 3） |
| `XI_LIVE_RECENT` | 最近窗口几轮 | `6`；`-1` 关掉 |
| `XI_LIVE_HINT` | `1` = 把插件那段「候选不是原话」提示也塞进 prompt（消融用） | `0` |
| `XI_LIVE_BOT` | 每个 persona 的临时库根目录 | 系统临时目录下 `xi-live-store` |
| `XI_MASTER_ID` / `XI_MASTER_NAMES` / `XI_SELF_ID` / `XI_SELF_NAMES` | 身份（名字/号） | 不填则用中性占位 |

## 自检

跑之前先单独验一次，不花题库：

```bash
node adapter/bridge.mjs < /dev/null     # 回一句 {"ok":true,...} 之前不该报错
python -c "from bench22.xisys_live import XiLive; s=XiLive(); print(s.store_dir)"
```

反过来，如果 `retrieve` 一直返回 0 条候选、只剩最近 6 轮，那通常不是坏了：
预激活是**按锚定事实和字面重叠**挑的，一个刚建的空库没有事实可挑，
它只在有历史之后才推得出东西。
